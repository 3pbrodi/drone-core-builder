# DroneBuilder Studio

Build a website called DroneCores, a modern drone configurator. I am a beginner working on an iPad, so please do all the coding for me.

Design: clean white background, blue accents, modern and beginner-friendly, responsive for iPad and desktop, inspired by BuildCores 3D.

Create a landing page with four large clickable options:

1. Create Custom Build

2. Choose Template

3. AI Build

4. Pre-Built Drones (DJI and other manufacturers)

For this first step, build only the landing page and working navigation to four separate sections. Use sample content. Make sure all buttons actually work when tapped on an iPad.

Use React and maintainable components. Do not build fake 3D functionality yet. Do not add a backend or paid services yet.

After building, show me the preview and explain how I can test the buttons. Do not just give me code; implement the website in this project.
